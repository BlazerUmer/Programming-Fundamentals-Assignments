# Programming Fundamentals Assignments & Homeworks

This repository contains my coursework, assignments, and homework submissions for the **Programming Fundamentals (PF)** course in C++.

---

## 📁 Repository Structure & Contents

### 1. Assignment 1
* **Focus:** Fundamental C++ syntax, basic logic building, arithmetic operators, and input/output streams.
* **Content:** Contains **17 individual C++ programs** solving a variety of introductory computational problems and conditional logic exercises.

### 2. Homework 1
* **Focus:** Program control flow, functions, and menu-driven applications.
* **Content:** A consolidated **menu-driven C++ application** featuring **11 selectable programs/tasks**, allowing the user to navigate and execute individual tasks dynamically from a single console interface.

### 3. Homework 2
* **Focus:** Iterative structures (`while` loops, `do-while` loops) and execution analysis.
* **Content:** Features **10 practical loop programs** alongside manual **dry run tracking** to demonstrate loop lifecycle, loop control variables, and state changes.

### 4. Assignment 2
* **Focus:** 1D arrays, nested loops, and the Fibonacci sequence.
* **Content:** Contains "6" C++ programs built around array handling, nested loop patterns, and Fibonacci-based problems, **including:**
* A menu-driven Fibonacci program with 4 selectable tasks, all powered by a single 1D array that stores the sequence once and is reused by every task:
*Look up any k Fibonacci numbers by index (e.g. F6 = 8)
*Print all Fibonacci numbers less than T
*Print all Fibonacci numbers between a Start and an End value
*Find the sum of the even-valued Fibonacci terms not exceeding four million (4613732)

## 🚀 How to Run

1. **Clone the repository:**
   ```bash
   git clone git@github.com:BlazerUmer/Programming-Fundamentals-Assignments.git
   cd Programming-Fundamentals-Assignments
   ```

2. **Compile any `.cpp` file using a C++ compiler:**
   ```bash
   g++ filename.cpp -o output
   ```

3. **Run the executable:**
   ```bash
   ./output    # Linux / Git Bash
   output.exe  # Windows Prompt
   ```
